# Performance

Generated by `cargo xtask perf`, which is a step of `cargo xtask ci`. Every number below was measured by the run that wrote this file; nothing here is typed in by hand, and a number that moved moved this document with it.

Each measurement carries a **band**. A time band is a baseline and a tolerance, because a duration is a property of the machine as much as of the code; a count band is a ceiling with no tolerance at all, because a count is a property of the design and reads the same on a slow machine, a fast one and under a debugger. A run outside any band fails the gate.

Stored runs: 129, under `docs/perf/runs/`, one tab-separated file each.

## Budgets

Every measurement that has a budget met it. A budget is what the design was supposed to cost and does not move with the measurement, so this is the statement a band cannot make: nothing here is merely no worse than it was.

## Where the frame's cost is

The three counters below are what decides whether the scene rebuild is the dominant cost of a frame, which is the question a retention scheme would be the answer to. They are recorded for every scenario rather than for the one somebody suspected, because a number that exists only where it was expected proves nothing about anywhere else.

And what each scenario found that no band expresses — a band says whether something got worse, and these say what the frame is actually doing:

- **scroll** — one row shift rebuilds 8 boxes and relays out 29 nodes, which is the row that arrived and not the port it arrived in; it still emits 404 primitives, which is the port, and is what a recycle frame's remaining cost is

- **cold-start** — this distribution is taken over a population of one, and it has to be: the second start in a process is a warm start wearing this scenario's name, so there is no second sample to take. Read the four figures as the one launch they are

- **kitchen-sink** — the tab traversal is inside the measured part now, and it is the widest distribution this scenario takes: p50 381.0 us, p99 450.3 us, max 450.3 us over 22 presses
