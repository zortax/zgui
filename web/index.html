Build and browser details

This canvas runs the Rust zgui engine as WebAssembly: reactive views, Stylo CSS, Cephal layout, Parley text, and retained paint scenes. It uses wgpu/Vello when WebGPU is available, with a Canvas 2D scene renderer as a fallback.

Renderer: Automatic · WebGPU · Canvas 2D

Prototype: one browser window, serial layout and style, bundled font. Desktop window management and browser screen-reader semantics are not implemented.
